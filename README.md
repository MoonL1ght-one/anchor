# 锚点 · 个人底层系统

四个模块，一件事：把那些**平时不愿意想、出事时又必须有人知道**的东西，提前写下来。

数据只存在这台电脑的浏览器里。没有账号，没有服务器，没有同步，也没有任何外部请求。

## 四个模块

### 1 个人宪法

写自己的价值观、原则、边界。不是给别人看的宣言，是给动摇时的自己看的字条。

- 三类分开写，每条可以附一句「为什么是这条」
- 空的时候可以从现成的写法里挑一条，再改成自己的话
- 「通读一遍」是全屏逐条阅读，方向键翻页，适合每年读两次
- 可以打印成一页，贴在看得见的地方

### 2 注意力账本

**不记录时长，只记录「我为什么分心」。**

每次分心填七个字段：当时在做什么、是什么把你带走的、之后去了哪、为什么、身体状态、环境。

记满几条后，中间那张「专注地形图」就浮出来了：

- 横轴是一天里的七个时段，纵轴是八种触发类型，颜色越深越常发生
- 右侧自动读出：最常走的路、最危险时段、最常见的身体状态、内部／外部动机比例
- 再给一条基于数据的具体建议（比如「畏难型分心：把任务切到小到不用下决心的一步」）
- 样本少于三条时，它会直接说「还看不出来」，不硬编结论

### 3 数字遗产清单

整理账号、文件与设备、写给具体的人的信、关键联系人。

- **只写密码提示，不写密码本身**，例如「常用名 + 出生年」「记在蓝色笔记本第 12 页」
- 每个账号要写明处置意愿：保留 / 注销 / 纪念账号 / 移交给某人
- **加密导出**（AES-GCM + PBKDF2，18 万次迭代）成一份文件交给亲人；口令自己另外保存
- 打印版是给亲人看的纸质清单，按「账号 → 文件 → 联系人 → 信」排好顺序

### 4 人生 B 计划

四种坠落情景的应急手册：失业、重病、分手或离婚、亲人离世。

- 每个情景都有预写的步骤（头 72 小时、钱、要通知的人、别做的事），可勾选、可改、可加
- 顶部的「现在只需要做这一件」永远只显示下一个未完成项
- 「应急卡」是全屏视图：三条待办 + 关键联系人，一次只做一件
- 可以打印，也可以放在手机里随时打开

## 怎么开始

**方式一：双击 `start.bat`（推荐）**

会起一个只绑定 `127.0.0.1:8787` 的本地服务并打开浏览器。固定端口很重要：浏览器的本地存储按「地址 + 端口」隔离，端口一变，之前写的东西就看不见了。关掉命令行窗口即停止服务，数据仍在。

**方式二：直接双击 `index.html`**

能看、能写、能存，Chrome / Edge 下连加密导出也正常。个别浏览器在 `file://` 下会关闭 Web Crypto，若加密按钮提示不支持，改用方式一。

需要 Python 3（只用标准库，无需安装任何依赖）。

## 数据在哪

在浏览器 `localStorage` 的 `anchor.personal.v1` 里，只在这台机器上。

会丢的情况，说清楚：清理浏览器数据、换浏览器、换电脑、用无痕窗口，都会让它消失。所以：

- 右上角「数据与备份」→ 导出全部（明文 JSON，适合自己归档）
- 「数据与备份」→ 加密导出（适合放在网盘，口令单独记）
- 导入时如果文件只含数字遗产清单，只覆盖那一部分，其他三个模块不动

## 一些设计上的取舍

- **不记时长**：时长会让人开始表演专注；原因才会改变下一次。
- **只写密码提示**：清单的目的不是让亲人破解你，而是让他们知道该找谁、该处理什么。
- **写「别做的事」**：应激状态下最贵的错误通常不是漏做了什么，而是在同一天做了太多决定。
- **允许空着**：四个模块都不要求填满。写一条也算开始。
- **没有提醒、没有积分、没有连续打卡**：它不打算变成又一个让你内疚的应用。

## 诚实的边界

- 它不是遗嘱，也不具备任何法律效力。涉及财产、监护、医疗意愿，请咨询律师并做正式文件。
- 它不是医疗或心理建议。如果情绪已经影响到生活，需要的是专业帮助，不是一个网页。
- 加密口令丢了就打不开，没有找回通道，这是设计而不是缺陷。
- 浏览器不是保险箱。真正的密码请用密码管理器，清单里只放线索。

## 文件结构

```
Anchor/
├── index.html          页面骨架与四个模块的容器
├── css/styles.css      纸与墨的视觉系统、响应式、打印样式
├── js/data.js          选项常量、起始模板、四种情景的手册骨架
├── js/core.js          状态与存储、模态框、加密、导入导出、打印
├── js/constitution.js  模块一
├── js/attention.js     模块二（含地形图与洞察计算）
├── js/estate.js        模块三
├── js/planb.js         模块四（含应急卡）
├── js/boot.js          启动、导航、首次说明
├── serve.py            本地静态服务器（固定端口 8787）
└── start.bat           Windows 双击启动
```

无构建步骤，无第三方库，无网络请求。改完文件刷新页面即可。
